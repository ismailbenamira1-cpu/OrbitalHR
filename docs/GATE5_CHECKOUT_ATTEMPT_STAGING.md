# Checkout attempt implementation
Internal test-only session creation helper added. No HTTP route invokes it. Stable Stripe idempotency key per immutable attempt; retries stop after 20 hours (conservative margin below Stripe's minimum 24-hour retention). An ambiguous response must be reconciled, not retried with a fresh key. Caller must persist customer ID, origin and attempt creation time before any Stripe call, then atomically bind returned session ID before returning URL. Existing reservation schema does not yet store all immutable parameters. No automatic release.
The helper uses the approved CAD 99 recurring price for sandbox experiments only. It does not implement the 12 paid month limit; never expose this checkout to customers until renewal/price transition terms and enforcement are approved. No live key, no live payment, no entitlement from redirect.
Next: durable attempt binding, customer creation idempotency, signed webhook transactional reconciliation, isolated staging SQL verification and end-to-end tests.
